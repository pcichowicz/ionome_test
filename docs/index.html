Ionome

An automated LC-MS metabolomics pipeline — from raw instrument files to annotated, cross-sample feature tables, statistically validated findings, and chromatographic verification — built to handle both single-standard runs and full multi-sample cohorts with QC.

View the repository on GitHub →

What this does

Ingests raw LC-MS files (.mzML / .mzXML), detects and aligns ion features across a full sample cohort, annotates adduct relationships, matches against a spectral library, and produces QC-checked, statistically validated, exportable feature tables — plus the volcano/PLS-DA/XIC plots to back up any biological claim it makes.

Two run profiles

standards_only for single-standard runs; cohort_with_qc for full multi-sample cohorts with cross-sample alignment. See Pipeline Overview.

Format-agnostic ingestion

Every stage that touches raw scans dispatches by file extension, so .mzML and .mzXML studies run through the same code path — no per-format special-casing downstream.

Evidence-based thresholds

RT and correlation tolerances come from real histograms of the data (RT-drift between QC mass-matched pairs; adduct correlation distributions), not defaults carried over from a different profile.

Stats + verification, not just detection

Volcano/heatmap/PLS-DA statistical stages, followed by XIC chromatogram verification of every statistically significant finding — see Gallery.

A real result

Run against MTBLS1301 (DKFZ, negative-mode HILIC, 3 cell lines × 3 replicates + pooled QC), the pipeline found a statistically significant metabolomic difference between the T691 and TUM6 cell lines — confirmed by three independent lines of evidence: volcano-plot statistics, PLS-DA class separation, and visually-verified XIC peak shapes for the underlying compounds.

Volcano — T691 vs TUM6, the strongest of three pairwise comparisons
PLS-DA — clean 3-way class separation, independently supporting the same signal
XIC — Hypotaurine, one of the significant features, visually confirmed as a real chromatographic peak
