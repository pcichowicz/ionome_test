ingestion

Registers each sample — and its raw file — into the pipeline's database, from a metadata CSV plus a directory of raw files.

sample metadata CSV + raw files → registered Sample records

Design note: raw file lookup dispatches by extension, so the same ingestion path handles both .mzML and .mzXML studies without per-format special-casing downstream.

scan_summary_cache

Extracts and caches per-scan summary data (retention time, MS level, etc.) from each sample's raw file, so downstream stages don't need to re-parse the raw file directly.

raw file → cached scan summary (parquet)

Design note: retention time handling is unit-aware (via pyteomics), so time values normalize correctly regardless of how the source format expresses them.

chromatogram_plotting

Generates per-sample TIC/BPC plots, plus (in cohort mode) an overlay of every sample's TIC/BPC colored by sample_role — the standard cohort-scale QC check for whether all runs look similar in shape/timing or whether one obviously deviates.

cached scan summary → per-sample + overlay TIC/BPC plots

Design note: role-color legend entries are deduplicated (3 QC samples don't produce 3 identical "QC" legend lines).

system_suitability

In standards-only mode, checks acquired precursor m/z values against known expected_mz reference values.

feature_detection

Per-sample MS1 peak picking into a feature list. Unchanged between profiles.

cached scan summary → per-sample feature list (parquet)

Validated on MTBLS1301: 6296→4611 features/sample after filtering, clean %CV (0.9–2.8%) across QC/NSC/T691/TUM6, RT max ~16.00 min across all samples (matches the known 16-min gradient).

feature_alignment new · cohort only

Aligns per-sample features into consensus features across the full cohort, matching the same underlying ion across samples despite small RT/mz drift.

12× per-sample feature lists → 19,409 consensus features

rt_tolerance_sec=15, mz_tolerance_ppm=10 — both evidence-based, see Design Decisions.

spectral_purity standards-only

Superseded in cohort mode — folded into library_matching's MS1 co-elution purity calculation (see Design Decisions). The old standards-only class is untouched and still used by that profile.

library_matching modified for cohort

Standards-onlyCohort-with-QC
validate_against_known_identityTrueFalse

Redesigned around the aligned/annotated table rather than known compounds: merges MS2 spectra across all contributing samples per adduct group, computes MS1 co-elution purity, tiered confidence (high_confidence/tentative/low_confidence/no_match, all thresholds tunable). library_assembly

Reframed from "row per confirmed compound" (a standards-only concept) to a full annotated feature table, with identification columns left-joined via adduct_group_id — every group member inherits its group's compound_name/confidence/score.

annotated + matched features → context.final_feature_table

Verified: a non-primary row correctly inherited its group's identification from another member of the same adduct group.

summary_stats_plotting

RSD histogram (QC replicates only) and PCA scores plot (log2 + impute-half-min + StandardScaler).

context.final_feature_table → RSD + PCA plots

MTBLS1301 result: 14.5% of features above the 20% RSD threshold (healthy). QC separated cleanly on PC1 (expected — pooled composition). NSC/T691 tightly clustered; TUM6 notably more spread on PC2 — consistent with TUM6 having the highest feature-count %CV back in feature_detection diagnostics.

volcano_plot new · cohort only

Pairwise Welch's t-test + Benjamini-Hochberg FDR correction, one comparison per pair of non-QC sample_roles. QC excluded (not a biological condition).

context.final_feature_table → per-comparison volcano plot + CSV

Real result on MTBLS1301 (post-fix): NSC_vs_T691 1 significant, NSC_vs_TUM6 0, T691_vs_TUM6 14. A replicate-sensitivity re-run excluding TUM6_rep_1 dropped T691_vs_TUM6 to 4 significant — see Gallery.

heatmap_clustering new · cohort only

Top-variance features (library-matched only, by default), row z-scored, hierarchical clustering on both axes.

context.final_feature_table → clustered heatmap + z-matrix CSV

MTBLS1301 result: TUM6_rep_1 clusters apart from its own replicate group — traced to a real, quantifiable technical difference (see Gallery), not excluded from the analysis on that basis alone.

plsda new · cohort only

3-class PLS-DA (NSC/T691/TUM6), leave-one-out cross-validation, permutation test, and VIP (variable importance in projection) scores — validation is the point here, since PLS-DA will find some separating direction even in pure noise at small n.

context.final_feature_table → score plot + LOO/permutation metrics + VIP CSV

MTBLS1301 result: clean 3-way separation on components 1–2.

xic_plotting new · cohort only

Extracted-ion chromatogram verification plots for volcano_plot's significant features only (see Design Decisions), labeled with compound_name when a library match exists.

volcano-significant feature IDs + raw scans → per-feature XIC plot + trace CSV

export modified for cohort

Serializes context.final_feature_table to feature_table.json/.csv (dynamic columns, no fixed schema needed), plus a QC report JSON.

Repositioned Now runs at the true end of the pipeline, after every statistics/verification stage, so it can aggregate their qc_metrics too — not just serialize the feature table. See Design Decisions.
